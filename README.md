# ZAHRAS FASHION Android app

Build the APK online (no Android Studio):
1. Create a free account at github.com and a new repository.
2. Upload everything in this folder (keep the .github folder).
3. Open the Actions tab, run "Build APK", wait about 3 minutes.
4. Open the finished run, download "zahras-fashion-apk", unzip it, and send app-debug.apk to your phone.
   On the phone, allow "Install unknown apps" when asked.

Shop link: edit SHOP_URL in app/src/main/java/com/zahras/fashion/MainActivity.java.
The shop link must be shared as "anyone with the link" so customers can open it.
